# Enhanced Wedding Invitation Assets + React Components

This pack adds an original SVG decorative system and connects the decorations to the React invitation with Framer Motion.

## Included SVG assets
- islamic-pattern.svg
- islamic-arch.svg
- mosque-outline.svg
- floral-corner-left.svg
- floral-corner-right.svg
- floral-divider.svg
- arabesque-divider.svg
- wedding-rings.svg
- lantern.svg
- crescent-stars.svg
- invitation-frame.svg
- leaf-sprig.svg
- gold-star.svg

## Expected photo assets
The React components expect:
- /public/images/groom.webp
- /public/images/bride.webp
- /public/images/couple-main.webp
- /public/images/nikkah-venue.webp
- /public/images/reception-venue.webp
- /public/images/gallery/01.webp through 08.webp

## Install
npm install framer-motion lucide-react qrcode.react
npm install tailwindcss @tailwindcss/vite

## Notes
The SVG artwork is original and included in this pack. Replace the sample photo paths with the couple's actual photos.
